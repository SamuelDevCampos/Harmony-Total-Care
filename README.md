## Estrutura

- `index.html` — HTML semântico com SEO e schema `Dentist`
- `assets/tailwind.css` — utilitários Tailwind compilados localmente
- `assets/site.css` — estilo da identidade e media queries
- `assets/site.js` — menu responsivo, formulário WhatsApp e navegação
- `assets/*.webp` — imagens fornecidas pelo usuário, convertidas/cortadas sem alterar conteúdo

## Publicação

1. Extraia o ZIP e publique `index.html` junto de `assets/` na raiz da hospedagem (Netlify, Vercel, GitHub Pages ou hospedagem HTML).
2. Após aprovação oficial, confirme **nome comercial**, telefone, endereço, horários, especialistas e o CRO-PJ/responsável técnico.
3. Atualize os dados tanto no HTML quanto no `application/ld+json` antes de publicar. Ative `index,follow` (no lugar de `noindex,follow`) somente quando houver aprovação.
4. Adicione `link rel="canonical"`, tags `og:url` e `og:image` absolutas, `sitemap.xml`, `robots.txt` e o domínio final. Cadastre a propriedade no Google Search Console.
5. Confirme direitos de uso/consentimento das fotografias e nomes de profissionais e observe as regras de publicidade odontológica do CFO/CRO.
6. Em uma emergência clínica, não dependa do formulário. Ele não envia ou armazena dados de saúde; apenas abre o WhatsApp após preencher nome e serviço.
